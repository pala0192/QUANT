# IntroductionToSoftwareConvergence

This repository contains a Python-based quantitative trading analysis platform. It provides:

- A Flask REST API server (`server.py`) for on‑demand strategy analysis.
- Market data loading via **yfinance**.
- Technical indicator calculation (EMA, Bollinger Bands, MACD, RSI, …).
- Signal generation and natural‑language interpretation.
- Gemini LLM based news sentiment scoring.
- Probability engine that combines technical, news, and volatility signals.
- Simple back‑testing and optimizer utilities.
- HTML templates with Plotly visualizations.

The project is ready to be deployed on Vercel, run locally, or extended with additional Antigravity customizations.
